# Day 3 - Lab 3: Users Groups and Sudo

## Objective

Practice Linux users, groups and controlled administrative privileges.

## Commands

useradd
passwd
groupadd
usermod
id
getent group
su
sudo
visudo

## Key Concepts

Users represent accounts.

Groups allow permissions to be managed for multiple users.

sudo allows authorized users to execute administrative commands.

## Security Principle

Give users only the privileges required for their job.
