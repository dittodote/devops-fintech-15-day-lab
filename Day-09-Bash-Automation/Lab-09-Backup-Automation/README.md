# Day 09 - Lab 09: Backup Automation

## Objective
Create a timestamped archive and verify its contents.

## Usage
./backup-app.sh
./backup-app.sh SOURCE_DIRECTORY BACKUP_DIRECTORY

## Concepts
- Bash arguments
- tar
- Timestamps
- File checks
- Archive verification

## Expected Result
A timestamped archive is created in the backup directory.

## Production Considerations
Configure retention, off-server storage, permissions,
monitoring, and regular restoration tests.
