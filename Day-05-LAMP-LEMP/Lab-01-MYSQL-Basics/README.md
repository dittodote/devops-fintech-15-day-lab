# Lab 01 - MySQL Basics

## Objective

Install and manage MySQL on Ubuntu.

## Commands

- apt install mysql-server
- systemctl status mysql
- systemctl start mysql
- systemctl enable mysql

## Verification

mysql --version
sudo systemctl is-active mysql
sudo mysql

## What I Learned

MySQL is a relational database server.

systemctl is used to manage the MySQL service.

## Troubleshooting

Checked MySQL service status using systemctl.
Checked logs using journalctl.
