# Lab 4 - CURL and HTTP

## Commands

curl http://example.com
curl -I http://example.com
curl -I https://example.com
curl -v https://example.com

## HTTP Status Codes

200 - Success
301 - Redirect
400 - Bad Request
401 - Unauthorized
403 - Forbidden
404 - Not Found
500 - Server Error
502 - Bad Gateway
503 - Service Unavailable
504 - Gateway Timeout
