# Day 10 - Lab 08: Docker Compose

## Objective
Deploy a FinTech application using Docker Compose.

## Files
- app.py
- Dockerfile
- compose.yaml

## Start
docker compose up -d --build

## Check
docker compose ps

## Logs
docker compose logs

## Stop
docker compose down

## Concepts
- YAML configuration
- Multi-service application management
- Container lifecycle
- Port mapping
- Compose networking
