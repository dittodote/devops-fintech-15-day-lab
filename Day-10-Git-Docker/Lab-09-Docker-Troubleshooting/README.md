# Day 10 - Lab 09: Docker Troubleshooting

## Objective
Investigate stopped containers and Docker resources.

## Commands
- docker ps -a
- docker logs
- docker inspect
- docker images
- docker volume ls
- docker network ls
- docker system df

## Test
Run an Ubuntu container with the false command.

## Expected Result
The container exits with code 1.

## Troubleshooting Process
1. Check container status.
2. Inspect logs.
3. Inspect exit code.
4. Check configuration.
5. Correct the problem.
6. Restart and verify.
