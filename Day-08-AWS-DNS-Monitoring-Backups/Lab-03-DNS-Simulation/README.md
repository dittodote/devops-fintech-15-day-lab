# Day 08 - Lab 03: DNS Simulation

## Objective
Practice hostname resolution and DNS queries locally.

## Commands
- cat /etc/hosts
- getent hosts payments.local
- dig example.com A
- dig example.com AAAA
- dig example.com NS
- dig example.com MX

## What I Learned
- /etc/hosts provides local hostname mappings.
- dig queries DNS.
- Public DNS and local hostname mappings are different.
- DNS records have different purposes.
