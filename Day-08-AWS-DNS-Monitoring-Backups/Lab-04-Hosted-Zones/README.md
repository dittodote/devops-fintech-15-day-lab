# Day 08 - Lab 04: Route 53 Hosted Zones

## Objective
Understand public and private hosted zones.

## Public Hosted Zone
Provides DNS answers intended for public DNS resolution.

## Private Hosted Zone
Provides DNS answers within associated VPCs.

## Important
A hosted zone does not automatically configure registrar
delegation or make an application reachable.

## Cost
Check current AWS pricing before creating a hosted zone.
