# Day 7 - Lab 03: EC2 Fundamentals

## Objective
Understand AWS EC2 instances and their components.

## Concepts
- Amazon Machine Image
- Instance type
- EBS volume
- Key pair
- VPC and subnet
- Security group
- Public IP
- Elastic IP

## FinTech Use Case

An EC2 instance can host an Nginx web server
and a web application.

## Security

Only required ports should be exposed.
SSH should be restricted to trusted source IPs.
Private keys must never be uploaded to GitHub.
