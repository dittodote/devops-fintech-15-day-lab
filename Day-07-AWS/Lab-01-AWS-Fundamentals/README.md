# Day 07 - Lab 01: AWS Fundamentals

## Objective
Understand AWS cloud services and their use in DevOps.

## Services Studied

- EC2: Virtual machines
- S3: Object storage
- IAM: Identity and access management
- VPC: Virtual networking
- Security Groups: Instance-level network access controls
- CloudWatch: Monitoring and logs
- Route 53: DNS service
- EBS: Block storage for EC2

## What I Learned

AWS provides cloud infrastructure and managed services.
DevOps engineers use these services to deploy, secure,
automate, and monitor applications.

## Cost and Security

- Check AWS pricing before creating resources.
- Protect credentials.
- Use least-privilege IAM policies.
- Remove unused resources after labs.
