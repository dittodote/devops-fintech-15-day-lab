# Day 7 - Lab 02: IAM and Security

## Objective
Understand AWS identity and permission management.

## Concepts

- IAM users
- IAM groups
- IAM roles
- IAM policies
- Multi-factor authentication
- Least privilege

## Security Practices

- Enable MFA.
- Avoid root access for everyday work.
- Prefer temporary credentials and IAM roles.
- Never commit access keys or secrets.
- Grant only required permissions.

## What I Learned

IAM controls authentication and authorization for AWS resources.

Authentication verifies identity.
Authorization determines which actions are permitted.
