# Day 7 - Lab 07: Elastic IP

## Objective
Understand static public IPv4 addresses in AWS.

## Concepts
- Automatically assigned public IPv4 address
- Elastic IP allocation
- Association with an instance
- Disassociation and release
- Public IPv4 pricing

## Verification
Test connectivity using the assigned public IP.

## Cleanup
Release the Elastic IP if it is no longer required.
Verify that no unused billable resources remain.
