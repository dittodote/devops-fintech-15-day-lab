# Day 11 - Lab 08: CI/CD Troubleshooting

## Objective
Learn to troubleshoot CI/CD failures.

## Common Issues
- Workflow not triggered
- Invalid YAML
- Python test failure
- Docker build failure
- Jenkins unavailable
- Jenkins pipeline failure

## Troubleshooting Tools
- GitHub Actions logs
- Jenkins Console Output
- docker logs
- docker ps
- docker inspect
- curl
- ss
